# 에러 코드

> 기준: `backend/src/main/java/com/ucamp/app/common/exception/ErrorCode.java`
> 코드 형식: `{도메인}_{3자리 번호}` — 새 코드 추가 시 이 문서에도 동일하게 기재한다.

## COMMON

| 코드 | HTTP 상태 | 메시지 | 발생 상황 |
|---|---|---|---|
| `COMMON_400` | 400 | 잘못된 요청입니다. | 요청 검증 실패, JSON 파싱 실패, 파라미터 타입 불일치·누락 |
| `COMMON_401` | 401 | 인증이 필요합니다. | 인증 정보 없음·만료 |
| `COMMON_403` | 403 | 접근 권한이 없습니다. | 권한 부족 |
| `COMMON_404` | 404 | 요청한 리소스를 찾을 수 없습니다. | 존재하지 않는 경로 |
| `COMMON_405` | 405 | 지원하지 않는 HTTP 메서드입니다. | 허용되지 않은 메서드 호출 |
| `COMMON_500` | 500 | 서버 내부 오류가 발생했습니다. | 예상하지 못한 시스템 예외 |

## AUTH

| 코드 | HTTP 상태 | 메시지 | 발생 상황 |
|---|---|---|---|
| `AUTH_001` | 409 | 이미 사용 중인 아이디입니다. | 고객 가입 시 회원 아이디 중복, 매장 가입 시 매장 아이디 중복 (동시 가입 포함) |
| `AUTH_002` | 401 | 아이디 또는 비밀번호가 올바르지 않습니다. | 없는 아이디 또는 비밀번호 불일치 (둘을 구분하지 않음) |
| `AUTH_003` | 403 | 사용할 수 없는 계정입니다. | 비밀번호는 맞지만 회원·매장 STATUS 가 INACTIVE |

## RESERVATION

| 코드 | HTTP 상태 | 메시지 | 발생 상황 |
|---|---|---|---|
| `RESERVATION_001` | 404 | 예약을 찾을 수 없습니다. | 없는 예약, 다른 고객의 예약을 확정 |
| `RESERVATION_002` | 409 | 이미 확정된 예약입니다. | 같은 예약을 두 번 확정 (중복 결제 콜백 등) |
| `RESERVATION_003` | 409 | 결제 대기 시간이 만료되었습니다. | 점유 만료(EXPIRED) 예약, 또는 만료 처리 전이라도 점유 만료 시각이 지난 예약을 확정 |
| `RESERVATION_004` | 409 | 결제 대기 중인 예약이 아닙니다. | 취소 처리 중·취소 완료 예약을 확정 |
| `RESERVATION_005` | 400 | 결제 금액이 예약금과 다릅니다. | 확정 시 결제 금액 ≠ 예약의 예약금(deposit) |

## NOTIFICATION

| 코드 | HTTP 상태 | 메시지 | 발생 상황 |
|---|---|---|---|
| `NOTIFICATION_001` | 404 | 구독을 찾을 수 없습니다. | 없는 구독, 다른 고객의 구독, 이미 해제한 구독을 수정·해제 |
| `NOTIFICATION_002` | 400 | 구독 유형에 맞지 않는 구독 대상입니다. | 업장 구독에 매장 ID 누락 또는 카테고리 ID·지역코드 포함, 카테고리 구독에 매장 ID가 있거나 카테고리 ID·지역코드 누락 |
| `NOTIFICATION_003` | 400 | 알림 희망 시간이 올바르지 않습니다. | 시작 시간이 종료 시간보다 같거나 늦음, 종료 시간이 이미 지남 |

## VACANCY

| 코드 | HTTP 상태 | 메시지 | 발생 상황 |
|---|---|---|---|
| `VACANCY_001` | 409 | 예약 접수가 마감된 시간입니다. | 시작 20분 전 이후 예약 클릭 |
| `VACANCY_002` | 409 | 결제 마감 시간이 지났습니다. | 시작 15분 전 이후 결제 확정 |
| `VACANCY_003` | 400 | 오늘부터 60일 이내만 예약할 수 있습니다. | 오늘 포함 60일을 넘는 날짜 예약·시간대 열기·닫기, 종료 시각이 이미 지난 열기·닫기 |
| `VACANCY_004` | 400 | 시각은 30분 단위여야 합니다. | 정각·30분이 아닌 예약 시작 시각, 예외 일정 시각 |
| `VACANCY_005` | 400 | 종료 시각은 시작 시각보다 뒤여야 합니다. | 예외 일정 종료 ≤ 시작 |
| `VACANCY_006` | 409 | 이미 예약된 시간입니다. | 점유·예약 완료·취소 처리 중인 예약과 시간이 겹침 (다른 고객이 결제 중인 경우 포함) |
| `VACANCY_007` | 400 | 판매가는 100원 단위이며 정가 이하여야 합니다. | 0원 이하, 100원 단위 아님, 정가보다 비싼 판매가 |
| `VACANCY_008` | 400 | 초임박 판매가는 일반 판매가 이하여야 합니다. | 초임박 판매가 > 일반 판매가 |
| `VACANCY_009` | 400 | 시간대 열기는 시작 30분 전까지 등록할 수 있습니다. | 시작 30분 전 이후 시간대 열기 등록·수정 |
| `VACANCY_010` | 404 | 시간대 열기·닫기 일정을 찾을 수 없습니다. | 존재하지 않는 열기·닫기 일정 수정·삭제 |
| `VACANCY_011` | 409 | 예약이 있는 시간은 닫을 수 없습니다. | 점유·예약 완료·취소 처리 중인 예약이 있는 시간을 닫기 등록·수정하거나 열기를 삭제·축소하거나 영업시간을 줄임 |
| `VACANCY_012` | 400 | 영업시간은 월요일부터 일요일까지 한 번씩 입력해야 합니다. | 영업시간 저장 시 요일 누락·중복 |
| `VACANCY_013` | 409 | 영업하지 않는 시간입니다. | 영업시간·시간대 열기 밖이거나 닫기와 겹치는 시간에 예약 |
| `VACANCY_014` | 400 | 영업일은 시작·종료 시각을 입력해야 합니다. | 휴무가 아닌 요일에 시작·종료 시각 누락 |
| `VACANCY_015` | 400 | 시술 소요 시간이 올바르지 않습니다. | 가용 시간 조회·예약 가능 검사에 0분 이하 소요 시간 전달 |
| `VACANCY_016` | 409 | 같은 시간에 진행 중인 예약이 있습니다. | 본인의 점유·예약 완료·취소 처리 중인 예약과 시간이 겹치는 예약 클릭 (매장 무관) |


## PAYMENT

| 코드 | HTTP 상태 | 메시지 | 발생 상황 |
|---|---|---|---|
| `PAYMENT_001` | 404 | 결제 정보를 찾을 수 없습니다. | 존재하지 않는 imp_uid 조회, 존재하지 않는 예약금결제 환불, 확정 예약에 결제 완료·환불 이력이 모두 없음 (취소 견적·취소) |
| `PAYMENT_002` | 502 | 결제 대행사 연동 중 오류가 발생했습니다. | 포트원 토큰 발급·조회·환불 실패 |
| `PAYMENT_003` | 409 | 환불할 수 없는 결제 상태입니다. | 결제 완료(PAID)·부분 환불(PART_REFUNDED)이 아닌 결제 환불 (이미 환불됨, 환불 처리 중(REFUND_PENDING) 등) |
| `PAYMENT_004` | 400 | 환불 금액이 올바르지 않습니다. | 환불 금액이 0원 이하이거나 남은 결제 금액보다 큼 |
| `PAYMENT_005` | 504 | 환불 결과를 확인하고 있습니다. 잠시 후 결제 상태를 확인해 주세요. | 포트원 환불 요청 후 응답을 받지 못했거나, 포트원 환불 후 DB 반영에 실패함. 결제는 REFUND_PENDING 으로 남는다 |

## CANCEL

| 코드 | HTTP 상태 | 메시지 | 발생 상황 |
|---|---|---|---|
| `CANCEL_001` | 404 | 취소할 예약을 찾을 수 없습니다. | 없는 예약, 고객이 남의 예약을·사장님이 다른 매장 예약을 취소 |
| `CANCEL_002` | 409 | 확정된 예약만 취소할 수 있습니다. | 점유(HOLD)·만료(EXPIRED) 예약 취소 |
| `CANCEL_003` | 409 | 이미 취소 요청된 예약입니다. | 취소 처리 중(CANCEL_PENDING)·취소 완료(CANCELLED) 예약 취소, 같은 예약 중복 취소 접수, 결제가 환불 처리 중·환불됨 상태인 예약 취소 |
| `CANCEL_004` | 409 | 시술 시작 이후에는 취소할 수 없습니다. | 시작 시각 이후 고객·사장님 취소 |
| `CANCEL_005` | 409 | 오늘 무료 취소를 이미 사용했습니다. | 견적 조회 후 같은 날 다른 무료 취소가 먼저 기록됨 (회원당 한국 날짜 하루 1회) |
| `CANCEL_006` | 400 | 환불액은 정책 환불액 이상, 납부 예약금 이하여야 합니다. | 고객 요청 대리 취소 환불액이 범위를 벗어남 |
| `CANCEL_007` | 409 | 환불 금액이 변경되었습니다. 견적을 다시 확인해 주세요. | 고객 직접 취소 실행 시 재계산한 환불액이 화면 견적과 다름 (자정 경계·무료 취소 10분 경과 등). 견적을 다시 조회해 재확인 |
