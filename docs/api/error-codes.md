# 에러 코드

> 기준: `backend/src/main/java/com/ucamp/app/common/exception/ErrorCode.java`
> 코드 형식: `{도메인}_{3자리 번호}` — 새 코드 추가 시 이 문서에도 동일하게 기재한다.

## COMMON

| 코드 | HTTP 상태 | 메시지 | 발생 상황 |
|---|---|---|---|
| `COMMON_400` | 400 | 잘못된 요청입니다. | 요청 검증 실패, JSON 파싱 실패, 파라미터 타입 불일치·누락 |
| `COMMON_401` | 401 | 인증이 필요합니다. | 인증 정보 없음·만료 |
| `COMMON_403` | 403 | 접근 권한이 없습니다. | 권한 부족 |
| `COMMON_404` | 404 | 요청한 리소스를 찾을 수 없습니다. | 존재하지 않는 경로 |
| `COMMON_405` | 405 | 지원하지 않는 HTTP 메서드입니다. | 허용되지 않은 메서드 호출 |
| `COMMON_500` | 500 | 서버 내부 오류가 발생했습니다. | 예상하지 못한 시스템 예외 |

## NOTIFICATION

| 코드 | HTTP 상태 | 메시지 | 발생 상황 |
|---|---|---|---|
| `NOTIFICATION_001` | 404 | 구독을 찾을 수 없습니다. | 없는 구독, 다른 고객의 구독, 이미 해제한 구독을 수정·해제 |
| `NOTIFICATION_002` | 400 | 구독 유형에 맞지 않는 구독 대상입니다. | 업장 구독에 매장 ID 누락 또는 카테고리 ID·지역코드 포함, 카테고리 구독에 매장 ID가 있거나 카테고리 ID·지역코드 누락 |
| `NOTIFICATION_003` | 400 | 알림 희망 시간이 올바르지 않습니다. | 시작 시간이 종료 시간보다 같거나 늦음, 종료 시간이 이미 지남 |

## VACANCY

| 코드 | HTTP 상태 | 메시지 | 발생 상황 |
|---|---|---|---|
| `VACANCY_001` | 409 | 예약 접수가 마감된 시간입니다. | 시작 20분 전 이후 예약 클릭 |
| `VACANCY_002` | 409 | 결제 마감 시간이 지났습니다. | 시작 15분 전 이후 결제 확정 |
| `VACANCY_003` | 400 | 오늘부터 60일 이내만 예약할 수 있습니다. | 오늘 포함 60일을 넘는 날짜 예약·시간대 열기·닫기, 종료 시각이 이미 지난 열기·닫기 |
| `VACANCY_004` | 400 | 시각은 30분 단위여야 합니다. | 정각·30분이 아닌 예약 시작 시각, 예외 일정 시각 |
| `VACANCY_005` | 400 | 종료 시각은 시작 시각보다 뒤여야 합니다. | 예외 일정 종료 ≤ 시작 |
| `VACANCY_006` | 409 | 이미 예약된 시간입니다. | 점유·예약 완료·취소 처리 중인 예약과 시간이 겹침 (다른 고객이 결제 중인 경우 포함) |
| `VACANCY_007` | 400 | 판매가는 100원 단위이며 정가 이하여야 합니다. | 0원 이하, 100원 단위 아님, 정가보다 비싼 판매가 |
| `VACANCY_008` | 400 | 초임박 판매가는 일반 판매가 이하여야 합니다. | 초임박 판매가 > 일반 판매가 |
| `VACANCY_009` | 400 | 시간대 열기는 시작 30분 전까지 등록할 수 있습니다. | 시작 30분 전 이후 시간대 열기 등록·수정 |
| `VACANCY_010` | 404 | 시간대 열기·닫기 일정을 찾을 수 없습니다. | 존재하지 않는 열기·닫기 일정 수정·삭제 |
| `VACANCY_011` | 409 | 예약이 있는 시간은 닫을 수 없습니다. | 점유·예약 완료·취소 처리 중인 예약이 있는 시간을 닫기 등록·수정하거나 열기를 삭제·축소 |
