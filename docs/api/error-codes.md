# 에러 코드

> 기준: `backend/src/main/java/com/ucamp/app/common/exception/ErrorCode.java`
> 코드 형식: `{도메인}_{3자리 번호}` — 새 코드 추가 시 이 문서에도 동일하게 기재한다.

## COMMON

| 코드 | HTTP 상태 | 메시지 | 발생 상황 |
|---|---|---|---|
| `COMMON_400` | 400 | 잘못된 요청입니다. | 요청 검증 실패, JSON 파싱 실패, 파라미터 타입 불일치·누락 |
| `COMMON_401` | 401 | 인증이 필요합니다. | 인증 정보 없음·만료 |
| `COMMON_403` | 403 | 접근 권한이 없습니다. | 권한 부족 |
| `COMMON_404` | 404 | 요청한 리소스를 찾을 수 없습니다. | 존재하지 않는 경로 |
| `COMMON_405` | 405 | 지원하지 않는 HTTP 메서드입니다. | 허용되지 않은 메서드 호출 |
| `COMMON_500` | 500 | 서버 내부 오류가 발생했습니다. | 예상하지 못한 시스템 예외 |

## AUTH

| 코드 | HTTP 상태 | 메시지 | 발생 상황 |
|---|---|---|---|
| `AUTH_001` | 409 | 이미 사용 중인 아이디입니다. | 고객 가입 시 회원 아이디 중복, 매장 가입 시 매장 아이디 중복 (동시 가입 포함) |
| `AUTH_002` | 401 | 아이디 또는 비밀번호가 올바르지 않습니다. | 없는 아이디 또는 비밀번호 불일치 (둘을 구분하지 않음) |
| `AUTH_003` | 403 | 사용할 수 없는 계정입니다. | 고객·관리자 로그인에서 비밀번호는 맞지만 회원(APP_USER) STATUS 가 INACTIVE. 매장 로그인은 해당 없음 |

| 코드 | HTTP 상태 | 메시지 | 발생 상황 |

| `AUTH_005` | 429 | 인증번호 요청 횟수를 초과했습니다. | 60초 재발송 대기, 번호당 시간당 10회, 서버 전체 시간당 100회 제한 |

## TERMS

| 코드 | HTTP 상태 | 메시지 | 발생 상황 |
|---|---|---|---|
| `TERMS_001` | 404 | 약관을 찾을 수 없습니다. | 가입·동의 요청에 등록되지 않은 약관 코드 |
| `TERMS_002` | 400 | 필수 약관에 모두 동의해야 합니다. | 고객 가입 시 최신 필수 약관(`AGE_14`·`SERVICE`·`PRIVACY`·`THIRD_PARTY`) 중 하나라도 누락 |
| `TERMS_003` | 409 | 알림 문자 수신 동의가 필요합니다. | 문자 수신(`SMS_NOTIFICATION`)에 동의하지 않은 고객이 희망 시간이 있는 구독을 등록하거나, 찜에 희망 시간을 넣도록 수정. 희망 시간 없는 업장 찜은 해당 없음. 프론트는 동의 모달 → `PUT /api/v1/users/me/terms-agreements/SMS_NOTIFICATION` → 재요청 |
| `TERMS_004` | 409 | 초보 시술 촬영 동의가 필요합니다. | 촬영(`MODEL_PHOTO`)에 동의하지 않은 고객이 초보 시술(`TREATMENT_TYPE = MODEL`) 예약 생성. 일반 시술은 검사하지 않음. 프론트는 동의 모달 → `PUT /api/v1/users/me/terms-agreements/MODEL_PHOTO` → 재요청 |

|---|---|---|---|
| `RESERVATION_001` | 404 | 예약을 찾을 수 없습니다. | 없는 예약, 다른 고객의 예약을 확정 |
| `RESERVATION_002` | 409 | 이미 확정된 예약입니다. | 같은 예약을 두 번 확정 (중복 결제 콜백 등) |
| `RESERVATION_003` | 409 | 결제 대기 시간이 만료되었습니다. | 점유 만료(EXPIRED) 예약, 또는 만료 처리 전이라도 점유 만료 시각이 지난 예약을 확정 |
| `RESERVATION_004` | 409 | 결제 대기 중인 예약이 아닙니다. | 취소 처리 중·취소 완료 예약을 확정 |
| `RESERVATION_005` | 400 | 결제 금액이 예약금과 다릅니다. | 확정 시 결제 금액 ≠ 예약의 예약금(deposit) |
| `RESERVATION_006` | 409 | 결제 대기 중인 예약이 있습니다. | 본인의 유효한 점유(HOLD)가 있는데 그 예약 ID를 `replaceReservationId`로 보내지 않고 다른 시술·시각 예약 클릭 (같은 시술·시각은 기존 점유를 돌려줌) |

## NOTIFICATION

| 코드 | HTTP 상태 | 메시지 | 발생 상황 |
|---|---|---|---|
| `NOTIFICATION_001` | 404 | 구독을 찾을 수 없습니다. | 없는 구독, 다른 고객의 구독, 이미 해제한 구독을 수정·해제 |
| `NOTIFICATION_002` | 400 | 구독 유형에 맞지 않는 구독 대상입니다. | 업장 구독에 매장 ID 누락 또는 카테고리 ID·지역코드 포함, 카테고리 구독에 매장 ID가 있거나 카테고리 ID·지역코드 누락 |
| `NOTIFICATION_003` | 400 | 알림 희망 시간이 올바르지 않습니다. | 시작·종료 중 하나만 있음, 시작이 종료보다 같거나 늦음, 종료가 이미 지남, 카테고리 구독에 시간이 없음. 업장 찜은 시작·종료를 둘 다 비울 수 있음 |
| `NOTIFICATION_004` | 409 | 같은 대상과 희망 시간의 구독이 이미 있습니다. | 구독 등록·수정 시 ACTIVE 구독 중 같은 대상(업장/카테고리·지역)과 같은 희망 시작·종료 시간이 이미 있음. 시간이 비어 있는 같은 매장 찜도 포함 |

받은 알림 조회·모두 읽음·스트림은 별도 코드가 없다. 비로그인은 `COMMON_401`, 고객이 아니면 `COMMON_403`, `category` 가 `RESERVATION`·`INTEREST` 가 아니면 `COMMON_400` 이다. 명세는 `docs/api/notification-inbox.md`.

## PAYMENT

| 코드 | HTTP 상태 | 메시지 | 발생 상황 |
|---|---|---|---|
| `PAYMENT_001` | 404 | 결제 정보를 찾을 수 없습니다. | 존재하지 않는 imp_uid 조회, 존재하지 않는 예약금결제 환불, 확정 예약에 결제 완료·환불 이력이 모두 없음 (취소 견적·취소) |
| `PAYMENT_002` | 502 | 결제 대행사 연동 중 오류가 발생했습니다. | 포트원 토큰 발급·조회·환불 실패 |
| `PAYMENT_003` | 409 | 환불할 수 없는 결제 상태입니다. | 결제 완료(PAID)·부분 환불(PART_REFUNDED)이 아닌 결제 환불 (이미 환불됨, 환불 처리 중(REFUND_PENDING) 등) |
| `PAYMENT_004` | 400 | 환불 금액이 올바르지 않습니다. | 환불 금액이 0원 이하이거나 남은 결제 금액보다 큼 |

| `PAYMENT_006` | 400 | 결제가 완료되지 않았습니다. | 결제 확인(`POST /payments/verify`) 때 포트원 결제 상태가 paid 가 아님 (ready, failed, cancelled) |
| `PAYMENT_007` | 400 | 예약과 맞지 않는 결제입니다. | 결제 주문번호(merchant_uid)가 `reservation-{reservationId}-` 로 시작하지 않음, 또는 같은 imp_uid 가 다른 예약에 이미 저장됨 |
